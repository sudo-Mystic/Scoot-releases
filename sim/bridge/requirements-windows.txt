#   winrt-runtime: WinRT projection machinery (the maintained successor
#     of the dead 'winrt' 1.0.x package, which has no wheels for modern
#     Python). The winrt.* namespaces below ship as separate packages.
#     Windows 10+ only.
# NOTE: dbus-next (the Linux bridge's BlueZ dependency) does NOT work on
# Windows. Do not try to install it there; use this file instead.

winrt-runtime
