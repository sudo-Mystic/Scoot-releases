05 / Good to know

A few things you might ask.

Is Scoot available on the Play Store? ⌄
Not yet. Download Scoot from this page and install the official Android APK. Future updates are also available inside the app.
Which scooters can I connect? ⌄
Scoot supports compatible TVS Jupiter 110 and 125 models, with partial support for TVS Ntorq 125. Feature availability depends on the scooter model and instrument cluster.
Does Scoot cost anything? ⌄
No. Scoot is free, has no ads, and doesn't require an account.
Do I need an internet connection? ⌄
Bluetooth pairing and supported live ride data can work without internet. Maps, place search and navigation may require data access.
Is Scoot made by TVS? ⌄
No. Scoot is an independent personal project and is not affiliated with, sponsored or endorsed by TVS Motor Company.
How can I check if my APK is genuine? ⌄
Use the verification tool in the download section. It calculates the file's SHA-256 hash locally in your browser and compares it to the latest published release. An exact hash match verifies that the file matches the published APK; it is not a general security guarantee.
